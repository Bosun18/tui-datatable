# tui-datatable

> Work in progress — not released yet.

Sortable, filterable data table widget for the experimental
[symfony/tui](https://github.com/symfony/tui) component.

## Planned features

Keyboard navigation, viewport scrolling, column sorting, filtering,
custom cell formatters, stylesheet-based theming. Keyboard-only in v1.

## Requirements

- PHP >= 8.4.1
- symfony/tui ^8.1

## Development

Under active development towards v0.1.0, so the API can still change
between commits.
